Raspberry Pi 2 • Lightweight YouTube

GTK Pipe Viewer

A lightweight graphical YouTube player for a Raspberry Pi 2, designed to avoid the overhead of running a full modern browser.

Requirements Install Launch Performance Troubleshooting

01 · Requirements

🧠 Raspberry Pi Pi 2 Model B
🐧 Operating System Raspberry Pi OS / Debian-based Linux
🌐 Network Ethernet or USB Wi-Fi
🔊 Audio HDMI, USB audio, or another working audio output
Open a terminal on your Raspberry Pi and run the commands below one at a time.

02 · Installation

1

Update your package list

sudo apt update
2

Install the basic dependencies

sudo apt install git mpv perl -y

mpv is the media player that can handle the actual video playback.

3

Download Pipe Viewer

git clone https://github.com/trizen/pipe-viewer.git
cd pipe-viewer
4

Install Pipe Viewer

sudo make install
If make install produces an error, stop there and read the error message. Dependencies for older software can change depending on your Raspberry Pi OS version.

03 · Start it

After installation, try: 

gtk-pipe-viewer

If everything installed correctly, the GTK graphical interface should open.

From there you can search for YouTube videos and send them to the media player.

04 · Make the Pi 2 happier

The Pi 2 is capable of video playback, but modern YouTube formats can be demanding. For smoother playback:

📺 Lower resolution Try 360p or 480p before higher resolutions.
🧹 Close other apps Free as much RAM and CPU as possible.
⚡ Use mpv Avoid running a heavyweight browser at the same time.
📡 Stable Wi-Fi A good network connection helps prevent buffering.

05 · Useful commands

# Launch GTK Pipe Viewer
gtk-pipe-viewer

# Check mpv
mpv --version

# Check your Pi architecture
uname -m

# Check Raspberry Pi OS
cat /etc/os-release

06 · Troubleshooting

❌ “gtk-pipe-viewer: command not found”

The installation probably did not complete successfully, or the program was installed somewhere outside your current PATH. Go back into the Pipe Viewer directory and inspect the output of sudo make install.

❌ The video does not play

YouTube frequently changes its delivery systems. Third-party players can therefore stop working until their extraction dependencies are updated.

❌ Video playback is extremely slow

Try a lower resolution and close other applications. The Pi 2 has only 1 GB of RAM and considerably less CPU power than newer Raspberry Pi boards.

❌ No sound

Check the Raspberry Pi's selected audio output and test another local audio/video file. If local playback also has no sound, the problem is probably system audio rather than Pipe Viewer.
